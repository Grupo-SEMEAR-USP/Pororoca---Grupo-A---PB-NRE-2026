## 🚀 Configuração

### 1. Clone o repositório

```bash
git clone https://github.com/Grupo-SEMEAR-USP/Pororoca---Grupo-A---PB-NRE-2026.git
```

Entre na pasta do projeto:

```bash
cd Pororoca---Grupo-A---PB-NRE-2026
```

### 2. Entre na pasta `Prog`

```bash
cd Prog
```

### 3. Crie o ambiente virtual

```bash
python3 -m venv .venv
```

### 4. Ative o ambiente virtual

**Linux/macOS:**

```bash
source .venv/bin/activate
```

**Windows:**

```powershell
.venv\Scripts\activate
```

### 5. Instale as dependências

Com a `venv` ativada:

```bash
python -m pip install -r requirements.txt
```

Pronto! 🎉

O ambiente está configurado e o projeto está pronto para ser executado/desenvolvido.
